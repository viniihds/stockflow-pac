# Matriz de Análise de Risco

Sistema de gestão de estoque de produtos. 

Vamos gerenciar quantidade, entrega, preço, prazos, gestão financeira e geração de relatórios.

Tecnologias: 

- React para o frontend
- Java com Springboot para o backend
- Banco de dados PostgreSql
- Github para guardar repositório
- Docker para subir ambientes
- Pipelines com GitHubActions  para automatizar testes unitários
